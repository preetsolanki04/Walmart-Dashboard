# Walmart Sales Dashboard 📊

## Project Overview

This project focuses on analyzing Walmart sales data to gain actionable business insights using **Excel-based analytics and dashboards**. The dashboard helps understand sales trends, performance by category, region-wise sales, and overall business growth.

The goal of this project is to demonstrate **data analysis, data visualization, and business intelligence skills** using a real-world retail dataset.

---

## Dataset

* **File:** `Walmart Dashboard.xlsx`
* **Data Type:** Retail sales data
* **Includes:**

  * Sales
  * Profit
  * Quantity
  * Category & Sub-category
  * Region / Store-level insights

---

## Tools & Technologies Used

* **Microsoft Excel**

  * Data Cleaning
  * Pivot Tables
  * Charts & Visualizations
  * Dashboard Design

---

## Key Features

* 📈 Interactive sales dashboard
* 🧮 KPI tracking (Sales, Profit, Quantity)
* 🗂 Category-wise and region-wise analysis
* 📊 Trend analysis for better decision-making
* 🎯 Business-focused insights

---

## Insights Generated

* Identified top-performing product categories
* Analyzed regional sales performance
* Tracked overall profit and sales trends
* Highlighted areas of improvement for business growth
